# IT Seminar Registration

Student registration form for ITP10 Event-Driven Programming Module 6.

## Run locally

Open `index.html` in a modern browser. The form validates all fields in the browser and displays a registration summary only after every check passes. No server or database is required.

## Project files

- `index.html` — accessible registration form
- `css/style.css` — responsive form styling
- `js/app.js` — validation, event handling, and summary rendering
- `screenshots/` — validation-error and successful-registration examples

The screenshots use fictional sample data.
